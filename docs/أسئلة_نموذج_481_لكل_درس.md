### 🔑 مفتاح الامتحان النموذجي

- **س1:** א) `س×1.25 = 500 ⟶ س = 400`. ב) `500×0.9 = 450`.
- **س2:** א) الأول `(2,0)`، الثاني `(5,0)`. ב) `2x−4=−x+5 ⟶ x=3, y=2 ⟶ (3,2)`. ג) القاعدة `5−2=3`، الارتفاع `2` ⟶ المساحة `3 وحدة²`.
- **س3:** א) `4/10 × 3/9 = 2/15`. ב) `2·(4/10×6/9) = 48/90 = 8/15`. ג) `6/9 = 2/3`.
- **س4:** א) `ACB = 90°` (على القطر). ב) `BAC = 180−90−35 = 55°`. ג) `BC = 10·sin35° ≈ 5.74`.
- **س5:** א) `a² = 64+25−2·8·5·0.5 = 89−40 = 49 ⟶ a = 7`. ב) `S = ½·8·5·sin60° ≈ 17.32`. ג) `sinB = 8·sin60°/7 ≈ 0.99 ⟶ B ≈ 81.8°`.
- **س6:** א) `f′ = 3x²−12x+9 = 3(x−1)(x−3)`. ב) `x=1` عظمى `f(1)=4`، `x=3` صغرى `f(3)=0`. ג) `f(2)=2, f′(2)=−3 ⟶ y=−3x+8`.
- **س7:** א) `x≠1`؛ عمودي `x=1`، أفقي `y=1`. ب) `f′ = (1·(x−1)−(x+3)·1)/(x−1)² = −4/(x−1)²`. ج) `f′ = −4/(x−1)² < 0` دائماً (لا يساوي صفراً) ⟶ لا قصوى.
- **س8:** א) `−x²+4x = x(4−x)=0 ⟶ x=0, 4`. ب) `F = −x³/3+2x²؛ F(4)=−64/3+32 = 32/3`. ج) الدالة موجبة على [0,4] ⟶ المساحة `= 32/3 وحدة²`.
