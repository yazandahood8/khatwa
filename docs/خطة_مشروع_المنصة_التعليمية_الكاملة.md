## 1. رؤية المشروع

### المشكلة
- الطالب يتفرج على فيديو تعليمي ويتجمد عند حل المسائل
- ما في أحد يساعده في اللحظة المناسبة
- المدرس الخصوصي غالي - 600 إلى 800 شيكل في الشهر
- الدورات الأونلاين الحالية مسجلة فقط - ما في تفاعل حقيقي
- الكتابة الرياضية على الكيبورد صعبة وغير طبيعية للطالب

### الحل
منصة تجمع بين:
- دروس فيديو مسجلة واضحة باللهجة العربية المحلية
- لوحة مفاتيح رياضية تفاعلية - لا حاجة لكتابة نصية
- مساعد ذكاء اصطناعي يشوف شغل الطالب ويوجهه خطوة بخطوة
- نظام ذكاء ثنائي - حلول مخزنة + Claude للطرق الجديدة
- سعر في متناول الجميع مقارنة بالمدرس الخصوصي

### الهدف
> أن يكون كل طالب عربي في إسرائيل عنده مدرس خصوصي ذكي يشتغل 24 ساعة 7 أيام بسعر كوب قهوة في الأسبوع

## 2. نموذج العمل والملكية

### هيكل الملكية
```
يزن داوود - المالك الوحيد - 100% الأرباح
              │
              ├── يسجل الدروس بنفسه
              │
              └── يتعاقد مع معلمين خارجيين
                          │
                          ├── المعلم يسجل محتوى متفق عليه مسبقاً
                          ├── دفعة ثابتة للمعلم - وليس نسبة من الأرباح
                          ├── يزن يملك المحتوى بالكامل بعد التسليم
                          └── لا التزام مستقبلي للمعلم
```

### لماذا هذا النموذج؟
- لا شراكة = لا خلافات مستقبلية
- المحتوى ملك المنصة للأبد
- التحكم الكامل بالجودة والتوقيت
- الأرباح كلها لك من اليوم الأول


## 4. الجمهور المستهدف

### الطالب - المستخدم المباشر
- طلاب المدارس العربية في إسرائيل من صف 7 إلى 12
- يعانون من مواد الرياضيات والفيزياء بشكل خاص
- يستخدمون الموبايل بشكل أساسي
- يريدون مساعدة فورية وليس مراجعة لاحقة

### الأهل - العميل الفعلي الذي يدفع
- يبحثون عن بديل للمدرس الخصوصي الغالي
- مستعدون للدفع مقابل تحسن النتائج
- القرار عندهم - وليس عند الطالب

### المقارنة التي تقنع الأهل

| | مدرس خصوصي | منصتنا بريميوم |
|--|-----------|----------------|
| السعر | 600-800 شيكل/شهر | 79 شيكل/شهر |
| التوقيت | ساعة محددة | 24 ساعة 7 أيام |
| الصبر | محدود | لا نهائي |
| التكرار | مرة وخلص | كم مرة تريد |
| تتبع التقدم | لا يوجد | تقرير أسبوعي للأهل |
| التوفير السنوي | - | 6,252 شيكل |

## 5. الميزات الرئيسية

### أولاً: مكتبة الدروس المسجلة
- فيديوهات مقسمة لوحدات قصيرة من 10 إلى 15 دقيقة
- مرتبة حسب المادة والصف والمستوى والموضوع
- جودة عالية وشرح باللهجة العربية المحلية
- إمكانية تحميل للمشاهدة بدون إنترنت في الباقة البريميوم

### ثانياً: لوحة الحل التفاعلية - الميزة الرئيسية
```
┌────────────────────────────────────────────┐
│  1  │  2  │  3  │  x  │  x²  │  x³  │  (  │
│  4  │  5  │  6  │  +  │  -   │  ×   │  )  │
│  7  │  8  │  9  │  √  │  ÷   │  =   │  ←  │
│  0  │  .  │  ±  │  ²  │  ³   │  |x| │  π  │
└────────────────────────────────────────────┘
```
- كل الرموز الرياضية جاهزة بضغطة
- لا حاجة لكتابة نصية أو تذكر كيف تكتب x²
- الذكاء الاصطناعي يقرأ الإدخال بشكل واضح 100%
- الطالب يبني حله خطوة بخطوة بشكل مرئي

### ثالثاً: Scratch Pad - مسودة حرة
- منطقة رسم بالإصبع للتفكير الحر
- ليست للإجابة الرسمية - للتفكير والتخطيط فقط
- يقدر يرسل مسودته للـ AI للاستفسار

### رابعاً: نظام المسائل المحلولة
- كل مسألة عندها أكثر من طريقة حل مخزنة
- الأخطاء الشائعة لكل مسألة محددة مسبقاً
- الـ AI يقارن مع الحلول المخزنة أولاً
- للطرق الجديدة يتحول Claude الكامل

### خامساً: لوحة تتبع التقدم
- نسبة الإنجاز لكل وحدة ودرس
- المسائل التي تعثر فيها الطالب (مراجعة ذكية)
- نقاط وإنجازات تحفيزية
- تقرير أسبوعي للأهل

### سادساً: Admin Panel - لك فقط
- رفع وتنظيم الفيديوهات
- إدخال المسائل والحلول والأخطاء الشائعة
- إدارة المستخدمين والاشتراكات
- متابعة الأرباح والإحصائيات
- مراجعة الطرق الجديدة التي اكتشفها الطلاب

## 6. نظام الذكاء الاصطناعي

### الفلسفة: المعلم السقراطي
```
لا يعطي الجواب مباشرة أبداً
يوجه بأسئلة تقود للتفكير الصح
يحدد الخطوة الخاطئة بدقة
يشجع ويحفز بالعربي دائماً
يتكيف مع مستوى الطالب
يحترم طريقة تفكير الطالب
```

### الطبقة الأولى: الحلول المخزنة
```
سريعة + رخيصة + دقيقة + موثوقة

الطالب يكتب خطوة
         ↓
AI يطابقها مع الحلول المخزنة
         ↓
يوجه الطالب بناءً على الـ hint المخزن
```

### الطبقة الثانية: Claude الكامل للطرق الجديدة
```
الطالب يستخدم طريقة غير معروفة
              ↓
AI يكتشف أنها لا تنتمي لأي طريقة مخزنة
              ↓
يتحول لـ Claude الكامل
              ↓
يتابع منطق الطالب ويحكم على الجواب النهائي
              ↓
إذا كانت الطريقة صحيحة - إشعار للـ Admin
لإضافتها للحلول المخزنة
```

### سير العمل الكامل
```
طالب يكتب خطوة بلوحة المفاتيح الرياضية
                    ↓
         هل تنتمي لطريقة معروفة؟
                    ↓
          نعم               لا
           ↓                 ↓
    يوجه بالحل          Claude الكامل
    المخزن              يتابع المنطق
           ↓                 ↓
    هل الخطوة صح؟      هل الجواب صح؟
     ↙          ↘       ↙         ↘
   نعم          لا    نعم          لا
    ↓            ↓     ↓            ↓
يشجعه      يوجهه   يشجعه      يشرح
ويطلب      بسؤال   ويوثق      الخطأ
التالية             الطريقة    بتدرج
```

### ردود الـ AI حسب الحالة

**الطالب يسلك طريقة معروفة وصح:**
```
منيح! خطوتك صح 👍
الآن فكّر في الخطوة الجاية -
إيش بتحاول تعمل؟
```

**الطالب يسلك طريقة معروفة وغلط:**
```
قريب! بس في شي صغير -
فكّر معي: لما بتنقل الحد لليمين
إيش بيصير للإشارة؟
```

**الطالب يستخدم طريقة جديدة وصح:**
```
وااو! هاي طريقة ما شفتها كثير 👏
بس منطقها صح تماماً
كمّل وأنا بتأكد معك كل خطوة
```

**الطالب يستخدم طريقة جديدة وغلط:**
```
فكرة إبداعية! بس في مشكلة
بالخطوة الثانية - فكّر معي:
إذا فعلت كذا إيش بيصير للطرف الثاني؟
```

**الطالب تعثر أكثر من 3 مرات:**
```
خلينا نرجع خطوة للوراء -
فكّر بالمفهوم الأساسي:
إيش معنى أن حاصل ضرب عددين = صفر؟
```

```
3. إذا خطأ - وجهه بسؤال واحد فقط لكل رد
```
