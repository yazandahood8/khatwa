# 🟦 الموضوع 1: الجبر والمعادلات

## الفصل 1 — معادلات من الدرجة الأولى
> الهدف: حلّ معادلة خطية بعزل المجهول، فتح الأقواس، توحيد المقامات، والمعامل الحرفي.

1. ⬜ **(سهل)** حلّ: `5x − 3 = 2x + 12`.
2. ⬜ **(متوسط)** حلّ: `3(2x − 1) = 4(x + 2) − 1`.
3. 🔶 **(صعب)** حلّ: `(2x + 1)/3 − (x − 2)/2 = 1`.
4. 🔴 **(تحدي)** حلّ واعزل `x` بدلالة `a` (بفرض `a ≠ 2`): `a·x − 4 = 2x + a`.

**🔑 المفتاح:** 1) `3x = 15 ⟶ x = 5`. 2) `6x − 3 = 4x + 7 ⟶ 2x = 10 ⟶ x = 5`. 3) `×6: 2(2x+1) − 3(x−2) = 6 ⟶ x + 8 = 6 ⟶ x = −2`. 4) `x(a − 2) = a + 4 ⟶ x = (a + 4)/(a − 2)`.

## الفصل 2 — معادلات من الدرجة الثانية
> الهدف: الحلّ بالتحليل والقانون العام والمميّز، وشرط عدد الحلول، والمعادلة الكسرية.

1. ⬜ **(سهل)** حلّ بالتحليل: `x² − 2x − 15 = 0`.
2. ⬜ **(متوسط)** حلّ بالقانون العام واحسب المميّز: `2x² − 5x − 3 = 0`.
3. 🔶 **(صعب)** لأيّ قيمة `k` يكون للمعادلة `x² − 6x + k = 0` حلّ واحد مضاعف؟
4. 🔴 **(تحدي)** حلّ المعادلة الكسرية: `6/x + x = 5` (بفرض `x ≠ 0`).

**🔑 المفتاح:** 1) `(x − 5)(x + 3) = 0 ⟶ x = 5, −3`. 2) `Δ = 25 + 24 = 49 ⟶ x = (5 ± 7)/4 ⟶ x = 3, −½`. 3) `Δ = 36 − 4k = 0 ⟶ k = 9`. 4) `x² − 5x + 6 = 0 ⟶ (x−2)(x−3)=0 ⟶ x = 2, 3`.

## الفصل 3 — معادلات من الدرجة الثالثة والعليا
> الهدف: الحلّ بإخراج العامل المشترك، فرق المربعين، والتحليل بالتجميع، ومبدأ «جداء = صفر».

1. ⬜ **(سهل)** حلّ: `x³ − 4x = 0`.
2. ⬜ **(متوسط)** حلّ: `2x³ − 6x² = 0`.
3. 🔶 **(صعب)** حلّ: `x³ + 2x² − 3x = 0`.
4. 🔴 **(تحدي)** حلّ بالتجميع: `x³ − 2x² − 9x + 18 = 0`.

**🔑 المفتاح:** 1) `x(x−2)(x+2)=0 ⟶ x = 0, 2, −2`. 2) `2x²(x−3)=0 ⟶ x = 0, 3`. 3) `x(x+3)(x−1)=0 ⟶ x = 0, −3, 1`. 4) `x²(x−2) − 9(x−2) = (x−2)(x−3)(x+3) = 0 ⟶ x = 2, 3, −3`.

## الفصل 4 — جُمَل معادلتين بمجهولين
> الهدف: حلّ نظام معادلتين بالإحلال والجمع، مع المضاعفة عند اللزوم.

1. ⬜ **(سهل)** حلّ بالجمع: `x + y = 7` ، `x − y = 3`.
2. ⬜ **(متوسط)** حلّ بالإحلال: `y = 2x − 1` ، `3x + y = 9`.
3. 🔶 **(صعب)** حلّ: `3x + 2y = 16` ، `5x − 2y = 8`.
4. 🔴 **(تحدي)** حلّ: `4x + 3y = 10` ، `2x − y = 5`.

**🔑 المفتاح:** 1) `2x = 10 ⟶ x = 5, y = 2`. 2) `5x − 1 = 9 ⟶ x = 2, y = 3`. 3) `8x = 24 ⟶ x = 3, y = 3.5`. 4) `×3 للثانية: 6x − 3y = 15 ⟶ جمعاً 10x = 25 ⟶ x = 2.5, y = 0`.

## الفصل 5 — قراءة الرسوم البيانية
> الهدف: استخراج القاطع والميل من الرسم، إيجاد معادلة خط، محور تماثل قطع، وقراءة تقاطع خطين.

1. ⬜ **(سهل)** خطّ يمرّ بـ `(0, 3)` و`(2, 7)`. ما قاطع `y` والميل؟
2. ⬜ **(متوسط)** خطّ يمرّ بـ `(1, 5)` و`(4, −1)`. أوجد معادلته `y = mx + b`.
3. 🔶 **(صعب)** قطع تربيعي يفتح للأعلى ويقطع محور x عند `x = −1` و`x = 5`. أوجد إحداثي `x` لرأسه.
4. 🔴 **(تحدي)** خطّان قُرئا من الرسم: `y = x + 1` و`y = −2x + 7`. أوجد نقطة تقاطعهما جبرياً.

**🔑 المفتاح:** 1) القاطع `3`، الميل `= (7−3)/(2−0) = 2`. 2) `m = (−1−5)/(4−1) = −2 ⟶ b = 7 ⟶ y = −2x + 7`. 3) `x = (−1 + 5)/2 = 2`. 4) `x + 1 = −2x + 7 ⟶ 3x = 6 ⟶ x = 2, y = 3 ⟶ (2, 3)`.

# 🟩 الموضوع 2: الدوال والرسوم البيانية

## الفصل 6 — الدالة الخطية
> الهدف: الميل والقاطع، صيغة `y = mx + b`، التوازي والتعامد، وتقاطع خطين.

1. ⬜ **(سهل)** أوجد الميل والقاطع للدالة `2x + 4y = 12` بصيغة `y = mx + b`.
2. ⬜ **(متوسط)** أوجد معادلة المستقيم الموازي لـ `y = 3x − 2` والمارّ بـ `(2, 5)`.
3. 🔶 **(صعب)** أوجد معادلة المستقيم العمودي على `y = ½x + 4` والمارّ بـ `(1, −2)`.
4. 🔴 **(تحدي)** المستقيمان `y = 2x + 1` و`y = −x + 7`: أوجد نقطة تقاطعهما وقاطعَي `y`.

**🔑 المفتاح:** 1) `y = −½x + 3` ⟶ الميل `−½`، القاطع `3`. 2) نفس الميل `3 ⟶ 5 = 6 + b ⟶ b = −1 ⟶ y = 3x − 1`. 3) الميل `−2` (سالب مقلوب ½) `⟶ −2 = −2 + b ⟶ b = 0 ⟶ y = −2x`. 4) `2x + 1 = −x + 7 ⟶ x = 2, y = 5 ⟶ (2, 5)`؛ قاطعا y: `(0, 1)` و`(0, 7)`.

---

## الفصل 7 — الدالة التربيعية
> الهدف: اتجاه القطع، الجذور، الرأس `x = −b/2a`، تقاطع محور y، وتحديد المعاملات من الرأس.

1. ⬜ **(سهل)** `y = x² − 6x + 5`: هل تفتح للأعلى أم للأسفل؟ وما جذورها؟
2. ⬜ **(متوسط)** أوجد إحداثيّي رأس `y = x² − 4x + 1`.
3. 🔶 **(صعب)** `y = 2x² − 8x + 6`: أوجد الجذور والرأس وتقاطع محور y.
4. 🔴 **(تحدي)** قطع `y = x² + bx + c` رأسه `(3, −4)`. أوجد `b` و`c`.

**🔑 المفتاح:** 1) للأعلى (`a = 1 > 0`)؛ `(x−1)(x−5)=0 ⟶ x = 1, 5`. 2) `x = 4/2 = 2, y = 4 − 8 + 1 = −3 ⟶ (2, −3)`. 3) `2(x−1)(x−3)=0 ⟶ x = 1, 3`؛ الرأس `x = 8/4 = 2, y = −2 ⟶ (2, −2)`؛ تقاطع y `(0, 6)`. 4) `−b/2 = 3 ⟶ b = −6`؛ `9 − 18 + c = −4 ⟶ c = 5`.

## الفصل 8 — الهندسة التحليلية: تقاطع خطّين ومساحة المثلث المحصور
> الهدف: تقاطع المستقيمات مع المحاور وببعضها، وحساب مساحة المثلث المحصور (سؤال ثابت في النموذج).

1. ⬜ **(سهل)** المستقيمان `y = x − 2` و`y = −2x + 7`: أوجد تقاطع كلٍّ منهما مع محور x.
2. ⬜ **(متوسط)** أوجد نقطة تقاطع المستقيمين `y = x − 2` و`y = −2x + 7`.
3. 🔶 **(صعب)** أوجد مساحة المثلث المحصور بين `y = x − 2` و`y = −2x + 7` ومحور x.
4. 🔴 **(تحدي)** المستقيمان `y = 2x` و`y = −x + 6`: أوجد تقاطعهما ومساحة المثلث المحصور بينهما وبين محور x.

**🔑 المفتاح:** 1) الأول `y=0 ⟶ (2, 0)`؛ الثاني `y=0 ⟶ (3.5, 0)`. 2) `x − 2 = −2x + 7 ⟶ 3x = 9 ⟶ x = 3, y = 1 ⟶ (3, 1)`. 3) القاعدة `= 3.5 − 2 = 1.5`، الارتفاع `= 1` ⟶ المساحة `= ½ × 1.5 × 1 = 0.75 وحدة²`. 4) `2x = −x + 6 ⟶ x = 2, y = 4 ⟶ (2, 4)`؛ القاعدة بين `(0,0)` و`(6,0)` `= 6`، الارتفاع `= 4` ⟶ المساحة `= 12 وحدة²`.

# 🟪 الموضوع 3: المتتاليات

## الفصل 9 — المتتالية الحسابية
> الهدف: الحدّ العام `aₙ = a₁ + (n−1)·d` ومجموع الحدود `Sₙ = n·(a₁ + aₙ)/2`، وإيجاد رقم الحدّ.

1. ⬜ **(سهل)** متتالية حسابية `a₁ = 3` والفرق `d = 4`. أوجد `a₁₀`.
2. ⬜ **(متوسط)** في متتالية حسابية `aₙ = 2n`. أوجد مجموع أول 20 حدّاً.
3. 🔶 **(صعب)** متتالية حسابية `a₁ = 5` و `d = 3`. أيّ حدّ يساوي 50؟
4. 🔴 **(تحدي)** متتالية حسابية `a₁ = 7` و `d = 2`. أوجد مجموع أول 10 حدود.

**🔑 المفتاح:** 1) `a₁₀ = 3 + 9·4 = 39`. 2) `a₁ = 2, a₂₀ = 40 ⟶ S₂₀ = 20·42/2 = 420`. 3) `50 = 5 + (n−1)·3 ⟶ n−1 = 15 ⟶ n = 16`. 4) `a₁₀ = 7 + 9·2 = 25 ⟶ S₁₀ = 10·32/2 = 160`.

**🔑 المفتاح:** 1) `a₅ = 3·2⁴ = 48`. 2) `162/2 = 81 = 3⁴ ⟶ n = 5`. 3) `q³ = 40/5 = 8 ⟶ q = 2`. 4) `q² = 54/6 = 9 ⟶ q = 3, a₁ = 2 ⟶ a₆ = 2·3⁵ = 486`.

# 🟨 الموضوع 5: حساب المثلثات في المستوى

> الهدف: تعريف sin و cos و tan في المثلث القائم، وإيجاد ضلع أو زاوية مجهولة.

1. ⬜ **(سهل)** في مثلث قائم الزاوية، المقابل للزاوية α هو 6 والوتر 10 (المجاور 8). احسب `sin α` و `cos α`.

**🔑 المفتاح:** 1) `sin α = 0.6`، `cos α = 0.8`. 2) `tan θ = √3 ≈ 1.732 ⟶ θ = 60°`. 3) `BC = 12 × sin35° ≈ 6.89 سم`. 4) `AB = √625 = 25`؛ `tan A = 24/7 ≈ 3.429 ⟶ A ≈ 73.7°`.

**🔑 المفتاح:** 1) نصف القطر `3√2 ≈ 4.24`؛ الحرف الجانبي `√34 ≈ 5.83 سم`. 2) `√25 = 5 سم` (نصف الضلع = 4). 3) نصف القطر `5√2`؛ `tan α = 12/(5√2) ≈ 1.697 ⟶ α ≈ 59.5°`. 4) القطر الفراغي `a√3`؛ `tan α = 1/√2 ≈ 0.707 ⟶ α ≈ 35.3°` (مستقلة عن a).

## الفصل 18 — المقاييس المركزية

## الفصل 19 — الانحراف المعياري
> الهدف: مفهوم σ، المقارنة بين مجموعتين بالتشتّت، وأثر الجمع بثابت على μ وσ.

1. ⬜ **(سهل)** ماذا يقيس الانحراف المعياري (σ)؟
2. ⬜ **(متوسط)** مجموعتان لهما المتوسط نفسه: أ σ=2، ب σ=5. أيّهما قيمها أكثر تقارباً؟
3. 🔶 **(صعب)** احسب الانحراف المعياري للقيم `2, 4, 6, 8, 10`.
4. 🔴 **(تحدي)** علامات معدّلها 70 وσ=6. أضاف المعلّم 5 علامات لكلّ طالب. ما المعدّل الجديد وما σ الجديد؟

**🔑 المفتاح:** 1) مدى **تشتّت** القيم حول المتوسط. 2) **المجموعة أ** (σ أصغر). 3) المتوسط `6`؛ مجموع مربّعات الانحرافات `40`؛ التباين `8` ⟶ `σ = √8 ≈ 2.83`. 4) المعدّل `75`؛ σ **يبقى 6**.

## الفصل 20 — التوزيع الطبيعي: قاعدة 68-95-99.7
> الهدف: منحنى الجرس ونسب السكّان ضمن مجالات الانحراف المعياري (μ±1σ ⟶ 68%، μ±2σ ⟶ 95%، μ±3σ ⟶ 99.7%).

1. ⬜ **(سهل)** ما نسبة القيم ضمن انحراف معياري واحد من المتوسط (μ±1σ)؟
2. ⬜ **(متوسط)** أطوال طلاب: μ=170 سم، σ=8 سم. بين أي طولين يقع ≈95% من الطلاب؟
3. 🔶 **(صعب)** درجات امتحان: μ=60، σ=10. ما نسبة الطلاب الذين حصلوا على أكثر من 70؟
4. 🔴 **(تحدي)** وزن أكياس: μ=500 غ، σ=20 غ. ما نسبة الأكياس بين 480 و540 غ؟

**🔑 المفتاح:** 1) `68%`. 2) `±2σ = ±16` ⟶ بين `154` و`186` سم. 3) `70 = μ+1σ`؛ خارج ±1σ = `32%` ⟶ الذيل الأعلى `16%`. 4) `480 = μ−1σ`، `540 = μ+2σ` ⟶ `34% + 47.5% = 81.5%`.

## الفصل 21 — التوزيع الطبيعي: Z-score والحسابات
> الهدف: الصيغة `z = (x − μ)/σ`، إيجاد نسبة أو قيمة فاصلة، والعمل عكسياً لإيجاد x.

1. ⬜ **(سهل)** احسب قيمة Z للعلامة `x=80` حيث `μ=70` و`σ=5`.
2. ⬜ **(متوسط)** علامة `x=64` وμ=70 وσ=4. احسب Z وفسّر إشارتها.
3. 🔶 **(صعب)** إذا كان `z=2` وμ=50 وσ=6، ما القيمة الأصلية x؟
4. 🔴 **(تحدي)** في توزيع طبيعي μ=100 وσ=15. ما نسبة القيم التي z لها بين −1 و+1؟

**🔑 المفتاح:** 1) `z = 10/5 = 2`. 2) `z = −6/4 = −1.5` (تحت المتوسط بـ1.5σ). 3) `x = 50 + 2×6 = 62`. 4) `z=∓1 ⟶ μ±1σ ⟶ 68%`.

# 🎯 نمط بجروت — محاكاة امتحان كامل (نموذج 35381)

> مبنيّ على البنية الرسمية الموثّقة في [التقرير البحثي](تقرير_بحثي_نموذج_381.md):

> ⚠️ هذه محاكاة تدريبية بأرقام من عندنا (ليست دورة رسمية). راعِ وسم ميكود 2026: أسئلة المتتالية الهندسية ومثلثات الفراغ قد لا تظهر في امتحان 2026 القديم.

**التعليمات للطالب:** «أمامك 6 أسئلة. أجب عن **4 أسئلة فقط** (25 نقطة لكل سؤال). اكتب كل خطوات الحلّ.»

### السؤال 1 — الجبر والدوال

- **א)** أوجد جذور الدالة (تقاطع محور x).
- **ב)** أوجد إحداثيّي رأس القطع.
- **ג)** أوجد نقطة تقاطع الدالة مع محور y.

- **א)** اكتب الحدود الأربعة الأولى.
- **ב)** أوجد الحدّ العشرين `a₂₀`.
- **ג)** أوجد مجموع أول 20 حدّاً `S₂₀`.

### السؤال 3 — النمو والاضمحلال
أودع شخص 8000 شيكل في بنك بفائدة مركّبة 5% سنوياً.
- **א)** اكتب دالة الرصيد `A` بعد `n` سنة.
- **ב)** كم يصبح الرصيد بعد سنتين؟
- **ג)** بلدة عدد سكّانها 10000 يتناقص 4% سنوياً — كم عددهم بعد سنتين؟

### السؤال 4 — حساب المثلثات (المستوى)
في مستطيل `ABCD`: الضلع `AB = 8 سم` والقطر `AC = 10 سم`.
- **א)** أوجد طول الضلع `BC`.
- **ב)** أوجد الزاوية بين القطر `AC` والضلع `AB`.
- **ג)** أوجد محيط المستطيل ومساحته.

### السؤال 5 — الإحصاء والاحتمالات
علامات طالب في أربعة امتحانات: `70، 80، 90، x`.
- **א)** إذا كان المعدّل 80، أوجد `x`.
- **ב)** أوجد وسيط العلامات الأربع.
- **ג)** نختار علامة عشوائياً من الأربع. ما احتمال أن تكون ≥ 80؟

### السؤال 6 — التوزيع الطبيعي
أطوال طلاب صف تتوزّع توزيعاً طبيعياً: المتوسط `μ = 165 سم` والانحراف المعياري `σ = 10 سم`.
- **א)** بين أي طولين يقع ≈68% من الطلاب؟
- **ב)** ما نسبة الطلاب الذين طولهم أكثر من 185 سم؟
- **ג)** احسب Z-score لطالب طوله 175 سم.

### 🔑 مفتاح الامتحان النموذجي

- **س1:** א) `(x−1)(x−3)=0 ⟶ x = 1, 3`. ב) الرأس `x = 4/2 = 2, y = 4 − 8 + 3 = −1 ⟶ (2, −1)`. ג) تقاطع y عند `(0, 3)`.
- **س2:** א) `4، 7، 10، 13`. ב) `a₂₀ = 4 + 19×3 = 61`. ج) `S₂₀ = 20(4 + 61)/2 = 650`.
- **س3:** א) `A = 8000·(1.05)ⁿ`. ב) `8000·(1.05)² = 8000·1.1025 = 8820 شيكل`. ג) `10000·(0.96)² = 10000·0.9216 = 9216 نسمة`.
- **س4:** א) `BC = √(10² − 8²) = √36 = 6 سم`. ב) `tan(∠CAB) = 6/8 = 0.75 ⟶ ∠ ≈ 36.87°`. ג) المحيط `= 2(8+6) = 28 سم`، المساحة `= 8×6 = 48 سم²`.
- **س5:** א) المجموع `= 4×80 = 320`؛ `x = 320 − 240 = 80`. ב) العلامات مرتّبة `70,80,80,90` ⟶ الوسيط `= (80+80)/2 = 80`. ج) القيم `≥ 80` هي `80,80,90` ⟶ `3/4`.
- **س6:** א) `μ±1σ ⟶ 165±10 ⟶ بين 155 و175 سم`. ב) `185 = μ+2σ`؛ خارج ±2σ = `5%` ⟶ الذيل الأعلى `2.5%`. ج) `z = (175−165)/10 = 1`.
