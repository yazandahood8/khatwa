# 🟧 القسم ب (تفاضل وتكامل الدوال المتسامية) 🆕

### 🔑 مفتاح الامتحان النموذجي

- **س1:** א) `a₅ = 4·3⁴ = 324`. ب) `S₄ = 4(3⁴−1)/2 = 4·40 = 160`. ج) `S∞ = 4/(1−½) = 8`.
- **س2:** א) الارتفاع الجانبي `√(3² + 4²) = √25 = 5` (نصف الضلع 4). ب) `tan α = 3/4 ⟶ α ≈ 36.87°`. ج) نصف القطر `4√2`؛ الحرف الجانبي `√(3² + (4√2)²) = √(9+32) = √41 ≈ 6.40`.
- **س3:** א) `f′ = eˣ + x·eˣ = eˣ(x+1)`. ب) `f′=0 ⟶ x=−1`؛ دنيا `f(−1) = −1/e ≈ −0.368`. ج) `f(0)=0, f′(0)=1 ⟶ y = x`.
- **س4:** א) `f′ = 1/x − 1 = 0 ⟶ x=1`؛ `f″=−1/x²<0` قصوى؛ `f(1) = −1`. ب) `ln e − ln 1 = 1`. ج) `f′(1) = 1/1 − 1 = 0` (مماس أفقي).
- **س5:** א) `f′ = cos x`؛ أصفار على [0,π] عند `x = π/2`. ب) `∫[0→π] sin x = [−cos x] = −cos π + cos 0 = 2`. ج) `∫[0→π/2] sin x = −cos(π/2)+cos0 = 1`.
