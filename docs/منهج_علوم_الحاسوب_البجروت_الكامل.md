**مسائل الدرس 7: جدول التتبع (מבחן)**

> جدول التتبع هو سؤال مهم جداً في البجروت! يُعطى كود وتتبع قيم المتغيرات خطوة بخطوة.

**مثال:**
```csharp
int x = 5, y = 3;
if (x > y)
{
    x = x - y;
    y = y + 1;
}
else
{
    y = x + y;
}
Console.WriteLine(x + " " + y);
```
1. ⬜ (سهل) تتبّع الكود أعلاه وأعطِ الطباعة النهائية.
2. ⬜ (متوسط) تتبّع: `int a=10; if(a%3==0) a=a/3; else a=a*2; Console.WriteLine(a);`
3. 🔶 (صعب) تتبّع برنامجاً بشرطين متشعبين من 6 خطوات.
4. 🔴 (تحدي) اكتب كوداً يُنتج الجدول التالي: عند x=3 يطبع 7، عند x=10 يطبع 15، عند x=7 يطبع 7.

```csharp
static int BinarySearch(int[] arr, int target)
{
    int low = 0, high = arr.Length - 1;
    while (low <= high)
    {
        int mid = (low + high) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

```csharp
public void Remove(int data)
{
    if (head == null) return;
    if (head.Data == data) { head = head.Next; return; }
    Node curr = head;
    while (curr.Next != null)
    {
        if (curr.Next.Data == data)
        {
            curr.Next = curr.Next.Next;
            return;
        }
        curr = curr.Next;
    }
}
```

```csharp
// BFS: المسح بالعرض (يستخدم Queue)
static void BFS(int[][] graph, int start)
{
    bool[] visited = new bool[graph.Length];
    Queue<int> q = new Queue<int>();
    q.Enqueue(start);
    visited[start] = true;
    while (q.Count > 0)
    {
        int node = q.Dequeue();
        Console.Write(node + " ");
        foreach (int neighbor in graph[node])
            if (!visited[neighbor])
            {
                visited[neighbor] = true;
                q.Enqueue(neighbor);
            }
    }
}
```
